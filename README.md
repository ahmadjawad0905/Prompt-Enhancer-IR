# 🚀 Prompt Enhancer with LLM (IR Project)

Welcome to the **Prompt Enhancement Lab** 🧠✨  
Where messy user queries get a glow-up and turn into smart, LLM-friendly prompts!

---

## 🧩 What is this project?

Ever typed a vague query like:
> "machine learning help"

And wished AI *just understood you better*?

This project does exactly that!

It takes a raw user query and:
- 🧠 Understands what the user *really means*
- 🏷️ Classifies the intent (Coding / Academic / General)
- ✨ Enhances the prompt using LLM magic
- ⚖️ Compares original vs enhanced results

Think of it as a **translator between humans and AI brains**.

---

## ⚙️ How it works

1. 🧑 User enters a query in Streamlit UI  
2. 🤖 Query is sent to a local LLM (Ollama: Mistral / Phi-3)
3. 🏷️ System classifies the query type
4. ✍️ Prompt is rewritten into a richer version
5. 🔁 Both original & enhanced queries are sent to LLM
6. 📊 Results are compared side-by-side
